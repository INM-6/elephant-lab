# jupyphant

A JupyterLab extension for visualizing Neo objects and Elephant results

Development install:

Required: npm, jupyter-lab (<2.0.0 currently, tested on 1.0.2; install using: `conda install jupyterlab=1.0.2 jupyterlab_server=1.0.0), ipython, neo, elephant, viziphant, matplotlib, viziphant

Install ipytree: 
https://github.com/QuantStack/ipytree

Install ipywidgets:
https://ipywidgets.readthedocs.io/en/stable/user_install.html

Install jupyphant itself:
See https://jupyterlab.readthedocs.io/en/stable/developer/extension_tutorial.html#extension-tutorial
